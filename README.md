# PokeAPI (Pokedex) - Ejercicio:

## Qué hace:
Este Ejercicio consulta información de Pokémon con la PokeAPI y muestra los resultados en la página.

## Qué se implementó:
- Búsqueda de Pokémon por nombre o id.
- Búsqueda de Pokémon por habilidad.
- Búsqueda de Pokémon por generación.
- Mensajes de error en la sección de resultados.

## Dónde se ve:
Los resultados se muestran en el contenedor con id (resultado).

## Cómo se usa:
1. Abre el index.html en el navegador.
2. No requiere el uso de APIkey.
3. Usa los botones para consultar Pokémon, habilidad o generación.
